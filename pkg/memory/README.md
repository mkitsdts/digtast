#

##

这是记忆模块，将记忆分为 长期记忆，短期记忆，对话记录 三大块

### 长期记忆

由短期记忆升华而来，有大模型筛选，次数筛选等，并有着清除功能。

长期记忆保存在 MEMORY.md 里，通过提示词注入到上下文。

### 短期记忆

大量短期记忆，是对话记录的提炼，通常会将对话内容分片提取。

基于简单的字符串匹配加入上下文，并为大模型提供记忆检索工具。

短期记忆保留的是提取内容，以及对应对话记录的偏移量，供检索时快速找到原文，避免信息失真

### 对话记录

整个调用过程的记录，在一定量后触发压缩，先删除工具调用的过程，然后进行提炼，写入短期记忆后再压缩，完成压缩后以tar.gz包形式存在，然后删除压缩后的原文。
